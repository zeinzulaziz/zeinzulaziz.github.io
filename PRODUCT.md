# PRODUCT.md

Context for design work on zeinzulaziz.github.io. Reads before UI changes.

## Users

- Potential freelance clients looking for WordPress, dashboard, or data work.
- Recruiters and peers checking the public track record.
- Readers arriving from a shared article.

## Product purpose

Show real public projects and writing from one person, and make it easy to open a
project, read a post, or start a conversation.

## Principles

- Honest numbers only. Years, certifications, and project counts come from real
  data, not invented metrics.
- Every link points somewhere that exists.
- Content first: no section exists only because a template has it.
- Calm over loud. One accent, spent only where it has to carry. The eclipse is
  the single loud thing on the page; everything around it stays quiet, and its
  light is kept pale enough that text crossing it still reads.
